# 🍡 ระบบสต็อก + สรุปยอดขาย ร้านขนม

เว็บง่าย ๆ สำหรับร้านขนม: ไดฟุกุ (ครีมนม · ช็อกโกแลต · ชาเขียว · สตรอเบอร์รี่ · โอริโอ้) และบราวนี่ ชิ้นละ **10 บาท** · ทาร์ตไข่ ชิ้นละ **5 บาท**

มี **2 เว็บแยกกัน** ใช้ข้อมูลชุดเดียวกัน (Google Sheet เดียว)

| เว็บ | โฟลเดอร์ | ใครใช้ | ทำอะไร |
|---|---|---|---|
| 🍡 **กรอกสต็อก** | `staff/` | **พนักงาน** | ☀️ **ก่อนขาย**: กรอก *ของเดิม* + *เพิ่ม* · 🌙 **หลังขาย**: กรอก *คงเหลือ* + เงินสด / เงินโอน / ไทยช่วยไทย + ค่าใช้จ่าย |
| 📊 **สรุปยอดขาย** | `owner/` | **เจ้าของร้าน** (ใส่รหัส) | ยอดขาย วันนี้ / สัปดาห์นี้ / เดือนนี้ · เลือกวันดูย้อนหลังได้ · เตือนเมื่อของที่หายไปไม่ตรงกับเงิน |

แต่ละโฟลเดอร์เป็นเว็บที่จบในตัว ไม่ได้ใช้ไฟล์ร่วมกัน — เว็บพนักงานไม่มีโค้ดดูยอดขายเลย ไม่มีลิงก์ไปเว็บเจ้าของร้าน
และไม่บอกพนักงานว่าควรได้เงินเท่าไหร่ ส่วนเว็บเจ้าของร้านดูได้อย่างเดียว กรอกสต็อกไม่ได้

## คิดยอดยังไง

- **ขายไป** = ของเดิม + เพิ่ม − คงเหลือ
- **ควรได้** = ขายไป × ราคา (รวมทุกรายการ)
- **ค่าใช้จ่ายจ่ายจากเงินสดเท่านั้น** — ช่องเงินสดให้กรอกเงินที่นับได้ในลิ้นชัก *หลังจ่ายค่าใช้จ่ายแล้ว*
- **ยอดขาย** = เงินสด + เงินโอน + ไทยช่วยไทย + ค่าใช้จ่าย
- ถ้ายอดขายไม่เท่ากับที่ควรได้ หน้าเจ้าของร้านจะขึ้น 🔻 **เงินขาด** หรือ 🔺 **เงินเกิน**
- ถ้า *ของเดิม* วันนี้ไม่เท่ากับ *คงเหลือ* ของวันก่อน ก็ขึ้น 📦 **ของเดิมหายไป/เกินมา** ด้วย
- สัปดาห์นับวันจันทร์ถึงวันอาทิตย์

ของเดิมจะใส่ให้อัตโนมัติจากคงเหลือของวันล่าสุด (แก้ได้ถ้านับแล้วไม่ตรง) · กรอกซ้ำวันเดิม = แก้ไข ไม่ได้ลงซ้ำ

## ลองเล่นก่อน (ไม่ต้องตั้งค่า)

ถ้าใน `config.js` ยังไม่ได้ใส่ `API_URL` เว็บจะเป็น **โหมดทดลอง** — ข้อมูลเก็บในเครื่องนั้นเครื่องเดียว
กรอกในเว็บพนักงานแล้วเปิดเว็บเจ้าของร้าน**ในเครื่องเดียวกัน**จะเห็นยอด (รหัสโหมดทดลอง `1234`)

## ติดตั้งใช้จริง (ประมาณ 10 นาที)

ข้อมูลเก็บใน Google Sheets ของเจ้าของร้านเอง ฟรี

### 1. สร้างชีต + วางโค้ดหลังบ้าน

1. เปิด [Google Sheets](https://sheets.new) สร้าง**ชีตใหม่เปล่า ๆ** ตั้งชื่อเช่น `ร้านขนม`
   — ใช้ชีตแยกของร้านนี้เอง **ไม่ต้องใช้ชีตหรือโค้ด Apps Script ของร้านอื่น** ไม่ต้องเอาอะไรมาจากที่อื่นเลย
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ [`google-apps-script/Code.gs`](google-apps-script/Code.gs) → กด 💾 บันทึก
4. ด้านซ้ายกด ⚙️ **การตั้งค่าโปรเจกต์** → เลื่อนลงไป **พร็อพเพอร์ตี้ของสคริปต์** → **เพิ่มพร็อพเพอร์ตี้**
   - `OWNER_PIN` = รหัสเจ้าของร้าน (เช่น `482913`) — **ต้องมี**
   - `STAFF_PIN` = รหัสพนักงาน — ไม่บังคับ แต่แนะนำ เพราะ URL หลังบ้านอยู่ใน config.js ที่ใครก็เปิดดูได้ (พนักงานใส่ครั้งเดียว เครื่องจำไว้)
   - ชื่อต้องพิมพ์ใหญ่ตรงตามนี้ · กด **บันทึกพร็อพเพอร์ตี้ของสคริปต์** ด้วย ไม่งั้นไม่จำ · ตั้ง/เปลี่ยนรหัสทีหลังได้ ไม่ต้อง Deploy ใหม่
5. กลับไปหน้าโค้ด เลือกฟังก์ชัน `setup` ด้านบน → กด **▶ เรียกใช้** → อนุญาตสิทธิ์ (ถ้าขึ้นว่าไม่ปลอดภัย กด *ขั้นสูง → ไปที่โปรเจกต์*)
   ชีตจะมีแท็บ **สต็อก** กับ **เงิน** ขึ้นมา

### 2. Deploy เป็นเว็บแอป

1. มุมขวาบน **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
2. ⚙️ เลือกประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
3. กด **ทำให้ใช้งานได้** → คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

### 3. ใส่ URL ลงเว็บ — ทั้ง 2 เว็บ

แก้ **ทั้ง** `staff/config.js` **และ** `owner/config.js` บน GitHub (กดรูปดินสอ ✏️) ใส่ URL เดียวกัน:

```js
SHOP_NAME: 'ชื่อร้าน',
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
```

กด **Commit changes**

### 4. เปิดเว็บ

**แบบง่าย — GitHub Pages** (ได้ 2 ลิงก์จาก repo นี้)

1. ใน repo นี้ไปที่ **Settings → Pages**
2. Source: **Deploy from a branch** · Branch: เลือก branch ที่มีโค้ดนี้ (ตอนนี้คือ `claude/bakery-sales-stock-system-7mwn9d`) / `(root)` → **Save**
3. รอ 1–2 นาที จะได้

- 🍡 เว็บพนักงาน: `https://imsummerr.github.io/Guy/staff/` (หรือ `https://imsummerr.github.io/Guy/` ก็พาไปหน้านี้)
- 📊 เว็บเจ้าของร้าน: `https://imsummerr.github.io/Guy/owner/` (เก็บไว้เอง ไม่ต้องส่งให้พนักงาน)

**แบบแยกขาดกัน — Netlify** (ได้ชื่อเว็บคนละชื่อเลย เช่น `xxx-stock.netlify.app` กับ `xxx-sales.netlify.app`)

1. [app.netlify.com](https://app.netlify.com) → **Add new site → Import an existing project** → เลือก repo นี้
2. **Base directory** ใส่ `staff` · Build command เว้นว่าง · Publish directory ให้เป็นโฟลเดอร์ `staff` (ถ้าช่องมี `staff/` นำหน้าให้แล้ว เว้นว่างได้) → Deploy
3. ทำซ้ำอีกเว็บ ใส่ `owner` แทน

เพิ่มลงหน้าจอมือถือให้ใช้เหมือนแอป: **iPhone** Safari → ปุ่มแชร์ → *Add to Home Screen* · **Android** Chrome → ⋮ → *เพิ่มลงในหน้าจอหลัก*

## แก้รายการสินค้า / ราคา

แก้ `ITEMS` บนสุดของ `Code.gs` ใน Apps Script แล้ว **Deploy ใหม่**
(การทำให้ใช้งานได้ → **จัดการการทำให้ใช้งานได้** → ✏️ → เวอร์ชัน: *เวอร์ชันใหม่* → ทำให้ใช้งานได้ — URL เดิม ไม่ต้องแก้ config.js)
ทุกครั้งที่วาง `Code.gs` ใหม่ ต้องทำขั้นนี้ ไม่งั้นเว็บยังใช้โค้ดเก่า
ถ้าลบหรือเปลี่ยนชื่อรายการ วันที่กรอกก่อนขายไปแล้วจะปิดยอดได้ตามปกติ (รายการที่เอาออกนับเป็นขาย 0)
ราคาที่บันทึกไปแล้วของวันก่อน ๆ ไม่เปลี่ยนตาม

ถ้าแก้ `Code.gs` อย่าลืมแก้ `ITEMS` ใน `staff/assets/app.js` ด้วย (ใช้แค่โหมดทดลอง)

## ไฟล์ในโปรเจกต์

```
staff/                     🍡 เว็บพนักงาน
  index.html                 ก่อนขาย / หลังขาย
  config.js                  ชื่อร้าน + URL หลังบ้าน
  assets/style.css           หน้าตา (สีละมุน)
  assets/app.js              เรียกหลังบ้าน + โหมดทดลอง
owner/                     📊 เว็บเจ้าของร้าน
  index.html                 สรุปยอดขาย
  config.js                  ชื่อร้าน + URL หลังบ้าน
  assets/style.css           หน้าตา
  assets/app.js              เรียกหลังบ้าน + โหมดทดลอง
  assets/report.js           คำนวณยอด / เทียบของกับเงิน
index.html                 ลิงก์หลักของ repo → พาไปเว็บพนักงาน
google-apps-script/Code.gs หลังบ้าน (วางใน Apps Script) ใช้ร่วมกันทั้ง 2 เว็บ
tests/run.js               เทสต์:  node tests/run.js
```
